# CREST-HISTORY-LONG · بستهٔ تولید

نسخهٔ بلند انگلیسی دربارهٔ تاریخ نشان باشگاه، با تصویر مجری و گرافیک برداری اختصاصی. تایم‌لاین گفتار از ضبط واقعی استخراج شده؛ مدت منبع مشتق‌شده ۲۲۵ ثانیه است و پس از آن ۸ ثانیه پایان برند قرار می‌گیرد.

## فصل‌ها

- 00:00 — The story behind the crest
- 00:26 — The four bars and the Senyera
- 01:28 — Sant Jordi and the cross
- 02:11 — From city arms to the 1910 crest
- 03:09 — A symbol bigger than football

## وضعیت بازبینی

ترنسکریپت برای **preview** آماده است؛ برای انتشار نهایی نیاز به گوش‌دادن و تأیید زیرنویس‌ها دارد. نقاط نیازمند شنیدن دوباره: عبارت مربوط به قلمروهای مدیترانه (01:08)، عبارت «original identity» (03:17)، و تلفظ پایانی «Més que un club» (03:38). اصلاحات املایی Senyera، Sant Jordi، Joan Gamper و coat of arms مطابق سناریو هستند و زمان واژه‌ها از صدای اصلی حفظ شده است.

## تصمیم‌های تصویر

- نشان در این نسخه تصویرسازی برداری تازه و وفادار به آرایش شناخته‌شدهٔ اجزاست؛ از فایل نشان کوتاه قبلی کپی نشده است.
- نمودار Crown of Aragon شماتیک و بدون مرزهای مدرن است.
- صلیب بارسلونا و انگلستان جدا و با برچسب مستقل می‌آیند؛ تصویر القای اقتباس مستقیم نمی‌کند.
- از عکس آرشیوی ثالث استفاده نشده است.
- ویدیوی اصلی در Git قرار نمی‌گیرد. ورودی خصوصی Workflow باید نسخهٔ مشتق‌شدهٔ ۲۲۵ثانیه‌ای با SHA-256 ثبت‌شده در manifest باشد.
