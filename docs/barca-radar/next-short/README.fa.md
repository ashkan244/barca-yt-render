# شورت بعدی — قالب Archive Split

ساختار از روی ویدیوی مرجع کاربر (۹۶.۵ ثانیه، ۴۶۴×۸۴۸) استخراج شد: هوک ۲ ثانیه‌ای تمام‌قاب مجری → بخش بالایی B-roll آرشیوی که با هر نام/مکان/زمان در گفتار عوض می‌شود (۲۹ کات نامزد، میانهٔ فاصله حدود ۲.۲ ثانیه) → بازگشت تمام‌قاب مجری روی جمله‌های کلیدی → کارت‌های تایپوگرافی کوتاه (مثل HALA MADRID / VISCA BARÇA) → جمع‌بندی. هیچ فوتیج یا تصویر از خود مرجع کپی نمی‌شود.

## ضبط مجری (برای کیفیت بالا)

- عمودی **۱۰۸۰×۱۹۲۰ یا 4K عمودی**، ۳۰fps، نور روبه‌رو، میکروفون یقه‌ای. (ضبط مربع ۷۲۰ قبلی برای قاب تمام‌قد عمودی کیفیت کم می‌آورد.)
- یک برداشت پیوسته؛ مکث‌ها و تکرارها را حذف می‌کنیم بدون تغییر سرعت گفتار.
- فایل را در Drive با دسترسی «هرکس با لینک» بگذار؛ شناسه فقط ورودی workflow است.

## مراحل تولید

1. inspect + checksum → متن گفتار (ASR) → بازبینی نام‌ها با مجری.
2. فهرست نام‌ها/مکان‌ها/سال‌های گفتار → `archive-queries.json` → workflow «Archive research» → انتخاب عکس فقط وقتی عنوان Commons نام همان شخص را دارد.
3. `<id>.spec.json` با `archive.cues` (هر کات روی مرز کلمه) + `archive-manifest.json`.
4. رندر workflow با `outputs=archive,clips`؛ تصاویر بازبینی در `renders/` همان پوشه commit می‌شوند.
5. توضیحات YouTube + `CREDITS.md` (نام عکاس‌های CC BY/BY-SA).
