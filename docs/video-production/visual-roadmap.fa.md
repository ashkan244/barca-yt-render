# نقشهٔ ارتقای بصری Barça Radar

هر قسمت تازه باید حداقل یک ارتقای بصری قابل‌مشاهده نسبت به قبلی داشته باشد، بدون خراب کردن قواعد حقوقی و صحت (عکس فقط با مجوز آزاد و نام درست، برد شماتیک با برچسب، عدد فقط با منبع).

## نسخه‌ها

| نسخه | خروجی | چه چیزی اضافه شد |
|---|---|---|
| v1 | CLASICO-SOURCE-SHORT | برد تاکتیکی شماتیک، کارت‌ها، کپشن کلمه‌به‌کلمه، فونت محلی، صدای نرمال‌شده |
| v2 | SHORT / LONG / CLIP-* | موتور JSON مشترک، نسخهٔ بلند ۱۶:۹ با فصل و end screen، شورت‌های کوتاه از یک ضبط، رندر موازی |
| v3 | CLASICO-SOURCE-ARCHIVE | قالب «Archive Split» مثل نمونهٔ مرجع: B-roll آرشیوی مجاز بالا، مجری پایین، punch-in تمام‌قاب، کارت تایپوگرافی، گرید سیاه‌سفید + grain، push-in، فلش کات، صداگذاری کات‌ها |
| v4 | همهٔ قالب‌ها (موتور) | چند تصویر در هر جمله (هر ۲–۳ ثانیه روی کلمهٔ نام)؛ «photo beat» در شورت/بلند (عکس شخص روی پنل برد هنگام گفتن نامش)؛ عکس روی کارت بازیکن؛ **کپشن کینتیک** (نام‌ها رنگ ثابت + pop)؛ **پیش‌نویس خودکار تدوین** `draft_cues.py` از روی زمان کلمه‌ها؛ پوشش B-roll قالب آرشیوی از حدود ۳۵٪ به ۷۷٪ |

| v5 | موتور یکپارچه (ادغام با main) | کپشن مشترک با SRT در همهٔ قالب‌ها؛ **برد خوانا** در همهٔ قالب‌ها: نام بزرگ، حداکثر ۲ نام کلیدی، zoom روی نیمهٔ مربوط زمین (`camera`)، حرکت مرحله‌ای مهره/فلش/فضا روی کلمهٔ گفته‌شده (`cues`)؛ قالب تطبیقی GPT به‌عنوان خروجی `adaptive` |

## صف ارتقاهای بعدی (به ترتیب اثر)

1. **کات‌اوت مجری (matte):** RVM موجود است؛ سر مجری کمی از لبهٔ B-roll بیرون بزند (pop-out). فقط بعد از تست لبهٔ مو روی ضبط واقعی.
2. **2.5D پارالاکس روی عکس‌های آرشیوی:** جدا کردن سوژه از پس‌زمینه و حرکت عمقی ملایم.
3. **کارت تاریخ/نقشه:** تایم‌لاین متحرک سال‌ها و نقشهٔ اسپانیا/کاتالونیا برای قسمت‌های تاریخی.
4. **تیتر روزنامهٔ بازسازی‌شده:** تایپ‌ست خودمان از تیترهای تاریخی (نه اسکن دارای حق نشر) با منبع.
5. **گرید بر اساس دوره:** دهه ۲۰–۴۰ سپیا، ۷۰ فیلم رنگی، امروز تمیز؛ یک LUT ثابت برای هر دوره.
6. **صدا:** riser قبل از کارت‌ها، ducking موسیقی زیر گفتار، room tone ثابت.
7. **تامبنیل A/B:** دو نسخه برای هر ویدیو و ثبت CTR بعد از ۴۸ ساعت.
