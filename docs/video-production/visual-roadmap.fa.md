# نقشهٔ ارتقای بصری Barça Radar

هر قسمت تازه باید حداقل یک ارتقای بصری قابل‌مشاهده نسبت به قبلی داشته باشد، بدون خراب کردن قواعد حقوقی و صحت (عکس فقط با مجوز آزاد و نام درست، برد شماتیک با برچسب، عدد فقط با منبع).

## نسخه‌ها

| نسخه | خروجی | چه چیزی اضافه شد |
|---|---|---|
| v1 | CLASICO-SOURCE-SHORT | برد تاکتیکی شماتیک، کارت‌ها، کپشن کلمه‌به‌کلمه، فونت محلی، صدای نرمال‌شده |
| v2 | SHORT / LONG / CLIP-* | موتور JSON مشترک، نسخهٔ بلند ۱۶:۹ با فصل و end screen، شورت‌های کوتاه از یک ضبط، رندر موازی |
| v3 | CLASICO-SOURCE-ARCHIVE | قالب «Archive Split» مثل نمونهٔ مرجع: B-roll آرشیوی مجاز بالا، مجری پایین، punch-in تمام‌قاب، کارت تایپوگرافی، گرید سیاه‌سفید + grain، push-in، فلش کات، صداگذاری کات‌ها |

## صف ارتقاهای بعدی (به ترتیب اثر)

1. **کپشن کینتیک:** بزرگ‌شدن کلمهٔ کلیدی، رنگ ثابت برای نام بازیکن/تیم، دو خط حداکثر.
2. **کات‌اوت مجری (matte):** RVM موجود است؛ سر مجری کمی از لبهٔ B-roll بیرون بزند (pop-out). فقط بعد از تست لبهٔ مو روی ضبط واقعی.
3. **2.5D پارالاکس روی عکس‌های آرشیوی:** جدا کردن سوژه از پس‌زمینه و حرکت عمقی ملایم.
4. **کارت تاریخ/نقشه:** تایم‌لاین متحرک سال‌ها و نقشهٔ اسپانیا/کاتالونیا برای قسمت‌های تاریخی.
5. **تیتر روزنامهٔ بازسازی‌شده:** تایپ‌ست خودمان از تیترهای تاریخی (نه اسکن دارای حق نشر) با منبع.
6. **گرید بر اساس دوره:** دهه ۲۰–۴۰ سپیا، ۷۰ فیلم رنگی، امروز تمیز؛ یک LUT ثابت برای هر دوره.
7. **صدا:** riser قبل از کارت‌ها، ducking موسیقی زیر گفتار، room tone ثابت.
8. **تامبنیل A/B:** دو نسخه برای هر ویدیو و ثبت CTR بعد از ۴۸ ساعت.
